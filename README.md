# 求职招聘小程序劳务派遣系统灵活用工APP源码搭建
获取源码：ym7k.com/19203/
一、这三个东西不是一回事
类型	核心	和普通招聘的差异
普通招聘	职位+简历+投递	基础
劳务派遣	派遣公司→用工单位→劳动者	三方关系、合同、社保、结算
灵活用工	平台接单、个人承揽、按单结算	个税、发票、资金合规
劳务派遣和灵活用工，最大的坑不在技术，在合规。

二、完整系统应该包含什么
部分	内容
求职者端	小程序/APP：职位、简历、投递、接单、结算
企业端	用工单位：发需求、管理派遣员工、考勤、结算
派遣公司端	管理劳动者、合同、社保、派单
平台后台	审核、订单、佣金、结算、发票、RBAC
后端 API	用户、企业、职位、合同、考勤、薪酬、结算
数据库	MySQL 表结构 + 初始化数据
文档	部署教程、数据库字典、接口文档
三、劳务派遣/灵活用工核心模块
劳务派遣

三方合同：派遣公司、用工单位、劳动者

员工管理：入职、离职、调岗

考勤：打卡、排班、加班

社保公积金：缴纳、增减员

薪酬结算：工资、派遣费、管理费

发票：派遣公司开给用工单位

灵活用工

任务发布、接单、验收

按单/按时结算

个税代扣（经营所得/劳务报酬）

发票：个人给平台开票（委托代征）
